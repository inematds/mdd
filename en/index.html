What it is

Dynamic direction, not static description

Most prompts return a still image with a caption. MDD treats the subject like a short film: it finds the visual conflict and resolves it through camera work, action, and continuity.

🎥 Direction, not description

Camera, action, continuity, emotion, and allowed effect in every shot. Finds the visual conflict before before building the storyboard.

📦 7 Fixed Blocks

Project card, scene package, style constraints, storyboard, director’s track, final prompt, and negative prompt — always in the same order.

♻️ A system that learns

Fixed template → shot and preset library → training by examples. Consistency that adapts to your taste.

How it works

From subject to ready-to-use prompt

Golden rule for every shot: camera + action + continuity + emotion + permitted effect. Without visual conflict, the video stays still — that’s why the skill finds the conflict first (product: problem × solution; real estate: ordinary space × experience; AI: blank screen × reveal).

Subject→ Visual conflict→ Progression→ Turning point→ Suspended impact
01 Card→ 02 Scene package→ 03 Style constraints→ 04 Storyboard→ 05 Director’s track→ 06 Final prompt→ 07 Negative prompt

User guide · step by step

From request to generated video

The skill doesn’t stall with questions: if format, duration, or style is missing, it assumes the strongest option for the visual conflict and states that assumption.

1

Install the skill

Just once. After that, it activates on its own when you ask for dynamic direction.

cp -r skill ~/.claude/skills/mestre-direcao-dinamica  # install
2

Request the package in natural language

Give it the subject. The skill returns all 7 complete blocks (card → negative prompt).

direção dinâmica sobre IA no cinema
3

Adjust through conversation

Change shots, format, duration, or preset without rewriting anything—just ask.

transforma em 12 tomadas e usa o preset de imobiliário
agora versão 9:16, 15s  # vertical for Reels/Shorts
4

Paste into the generation tool

O block 06 (final prompt) goes in the prompt field; the block 07 (negative) in the negative field. The main call outside from the prompt (added in editing), so the AI doesn’t render distorted text.

# 06 → prompt · 07 → negative · CTA → in the edit

Roadmap · the 3 levels

From template to a system that learns

MDD was designed with 3 increasingly sophisticated levels—and the skill already handles all three. Available presets: Action/sports · Premium product · Technology/AI · Real estate · Event · Emotional story.

Level 1
Fixed templateThe 01–07 structure never changes. The AI always fills in the same blocks — ensuring consistency. It’s the SKILL.md.
Level 2
Style and shot libraryThe AI chooses the camera, pacing, and effects based on the subject, drawing from references/biblioteca-tomadas.md e references/presets.md. It stops feeling rigid.
Level 3
Training by examplesYou build up packages in exemplos/ and the AI learns your specific taste—through conversation, presets, or your own prompt generator.
