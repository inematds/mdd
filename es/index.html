Skill para Claude Code · dirección de video

Cualquier tema se convierte en un paquete de video dinámico

El MDD dirige una escena con movimiento, intención y continuidad, lista para generar en Seedance, Kling, Runway, Veo o Luma. No se trata de «una persona usando X»: la cámara cambia por un motivo, la acción avanza y hay un cierre contundente.

Qué es

Dirección dinámica, no descripción estática

La mayoría de los prompts devuelve una imagen estática con subtítulos. MDD trata el tema como un cortometraje: encuentra el conflicto visual y lo resuelve con cámara, acción y continuidad.

🎥 Dirección, no descripción

Cámara, acción, continuidad, emoción y efecto permitido en cada toma. Encuentra el conflicto visual antes de montar el storyboard.

📦 7 bloques fijos

Ficha del proyecto, paquete de escena, restricciones de estilo, storyboard, guía del director, prompt final y prompt negativo: siempre en el mismo orden.

♻️ Sistema que aprende

Plantilla fija → biblioteca de tomas y presets → entrenamiento con ejemplos. Una consistencia que se adapta a tus gustos.

Cómo funciona

Del tema al prompt listo

Regla de oro para cada toma: cámara + acción + continuidad + emoción + efecto permitido. Sin conflicto visual, el video queda estático; por eso la skill encuentra primero el conflicto (producto: problema × solución; inmueble: espacio común × experiencia; IA: pantalla vacía × revelación).

Tema→ Conflicto visual→ Progresión→ Cambio→ Impacto en suspenso
01 Ficha→ 02 Paquete de escena→ 03 Restricciones de estilo→ 04 Storyboard→ 05 Guía del director→ 06 Prompt final→ 07 Prompt negativo
Requisitos previos

Qué necesitas para ejecutarla

Es una skill de texto puro, ligera. Solo necesitas Claude Code y, al final, una herramienta de generación de video para pegar el prompt.

El agente que ejecuta la skill. La skill se activa con lenguaje natural.

Guía de uso · paso a paso

Del pedido al video generado

La skill no se detiene a hacer preguntas: si falta el formato, la duración o el estilo, asume la opción más potente para el conflicto visual y declara la suposición.

1

Instala la skill

Solo una vez. Después se activa automáticamente cuando pides dirección dinámica.

cp -r skill ~/.claude/skills/mestre-direcao-dinamica  # instala
2

Pide el paquete con lenguaje natural

Da el tema. La skill devuelve los 7 bloques completos (ficha → prompt negativo).

direção dinâmica sobre IA no cinema
3

Ajusta conversando

Cambia tomas, formato, duración o preset sin reescribir nada: solo tienes que pedirlo.

transforma em 12 tomadas e usa o preset de imobiliário
agora versão 9:16, 15s  # vertical para Reels/Shorts
4

Pega en la herramienta de generación

O bloque 06 (prompt final) va en el campo de prompt; el bloque 07 (negativo) en el campo negativo. El llamado principal queda fuera del prompt (va en la edición), para que la IA no renderice texto torcido.

# 06 → prompt · 07 → negativo · CTA → en la edición

Roadmap · los 3 niveles

De plantilla a sistema que aprende

El MDD se diseñó con 3 niveles de sofisticación creciente, y la skill ya incluye los tres. Presets disponibles: Acción/deporte · Producto prémium · Tecnología/IA · Inmobiliario · Evento · Historia emocional.

Nivel 1
Plantilla fijaLa estructura 01–07 nunca cambia. La IA siempre completa los mismos bloques, lo que garantiza consistencia. Es el SKILL.md.
Nivel 2
Biblioteca de estilos y tomasLa IA elige la cámara, el ritmo y los efectos según el tema, tomando elementos de references/biblioteca-tomadas.md e references/presets.md. Deja de ser rígido.
Nivel 3
Entrenamiento con ejemplosAcumulas paquetes en exemplos/ y la IA aprende tus gustos específicos, mediante conversaciones, presets o tu propio generador de prompts.
